# Heartwell Character Dossier

This package is the existing Charactermancer restyled to visually align with the Heartwell campaign material.

The game data, state model, rules engine, event handlers, drag-and-drop behavior, save/load behavior, and step structure are preserved. The redesign changes the presentation layer: typography, parchment/paper surfaces, midnight-blue and blood-red palette, muted-gold framing, gothic dossier treatment, chapter-style navigation, controls, gauges, forms, and responsive behavior.

The Heartwell reference uses a parchment palette, blood red, dark blue, muted gold, and fonts including Fira Sans Extra Condensed and Voltaire; those cues are reflected in `styles.css` and `index.html`.

Open `index.html` in a modern browser. The app loads its existing JavaScript modules locally. Google Fonts and the campaign-inspired background textures are remote resources, so an internet connection improves visual fidelity.
