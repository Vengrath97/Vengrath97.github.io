# Artykuły Echtra

W tym folderze umieszczaj artykuły świata Echtra.

Każdy artykuł powinien być osobnym plikiem `.html`. Nazwa pliku staje się jego identyfikatorem, np. `irgaela.html`.

Plik artykułu powinien zawierać wyłącznie treść wpisu — bez `<!doctype>`, `<html>`, `<head>` ani wspólnej nawigacji strony.

Skopiuj `_TEMPLATE.html`, zmień jego nazwę i uzupełnij treść.

Indeks kompendium automatycznie wykrywa pliki `.html` znajdujące się w tym folderze. `_TEMPLATE.html` jest pomijany.
